# CorePulse

Real-Time System Intelligence Dashboard for Windows

![CorePulse Banner](assets/banner_image.png)

## Overview

CorePulse is a lightweight desktop application built with:

- Wails
- React
- Go
- Tailwind CSS

It provides real-time monitoring of system performance and hardware statistics through a modern glassmorphism dashboard.

---

## Features

### Real-Time Monitoring

- CPU Usage
- RAM Usage
- Disk Usage
- Active Processes
- System Uptime

### Network Analytics

- Upload Speed
- Download Speed
- Total Uploaded Data
- Total Downloaded Data

### Live Charts

- CPU Activity Graph
- RAM Usage Graph

### System Information

- Hostname
- Operating System
- Platform
- CPU Model
- CPU Core Count
- Total RAM
- Used RAM
- Disk Information

### Modern Interface

- Glassmorphism UI
- Realtime Updates
- Responsive Layout
- Lightweight Performance

## Development

### Clone

git clone https://github.com/Sridhar725S/CorePulse.git

### Frontend

cd frontend
npm install

### Backend

go mod tidy

### Run

wails dev

### Build

wails build
